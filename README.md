# 箫声袅袅 - 玉箫加速模块

## 项目简介

本项目仅包含游戏的前端静态资源（HTML / CSS / JavaScript / 图片），不包含任何后端服务。所有资源均引用自原始 CDN，部署后即可通过浏览器访问。

## 文件说明

### 🎯 核心功能文件

|文件|用途|依赖|
|-|-|-|
|`index.html`|**演示页面**，包含完整的内联 Hook 引擎、UI 逻辑和视频联动|独立运行|
|`玉箫加速.js`|**生产模块**，ES5 IIFE 封装，暴露 `window.$hookTimer` API|独立运行|
|`xiao02.webm`|**吹箫引凤绿幕视频**（408×725，1:1.78 比例），触发球动画|被 `index.html` 引用|
|`xiao\_x\_panel.png`|面板内**玉箫静态图片**（88×180，1:2.05 比例）|被 `index.html` 引用|
|`xiao\_x\_transparent.png`|透明背景玉箫图片||

### 🎮 游戏原始资源（来自"斗罗大陆H5"）

|文件|用途|
|-|-|
|`skin.js`|**游戏皮肤配置**，定义了 3 套皮肤的资源路径（登录背景、logo、加载图等）|
|`md5.js`|**MD5 加密算法**，用于数据签名或验证|
|`enter.js`|**游戏登录入口**，包含多语言配置（中/英）、登录流程、SDK 通信、加载逻辑|
|`cc.js`|**轻量级 2D 游戏引擎**，包含 Canvas 渲染、显示对象、事件系统、文本渲染等|

### 🖼️ 登录界面资源（`img/` 目录）

|文件|用途|
|-|-|
|`x5\_login.json`|**sprite 图集配置**，定义登录界面各元素的坐标和尺寸|
|`x5\_login.png`|**sprite 图集图片**，包含登录按钮、背景、图标等|
|`bg.jpg`|登录界面**主背景图**|
|`bottom\_1.jpg`、`bottom\_2.jpg`|登录界面**底部装饰图**|
|`denglu\_img\_logo.png`|登录界面**游戏 logo**|
|`loadingFlower.png`、`loadingRound.png`|**加载动画资源**（花朵旋转效果）|
|`DISCLAIMER.md`|免责声明|

**操作方式：**

* 点击左侧触发球 → 打开/关闭控制面板
* 拖拽触发球 → 移动位置（记忆跨页面）
* 键盘 `\[` `]` → 切换洞音档位
* 键盘 `0` → 归韵（重置为 1x）
* 键盘 `P` → 铭记（持久化当前速度）
* 键盘 `Esc` → 关闭面板
